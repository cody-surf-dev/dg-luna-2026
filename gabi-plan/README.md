# План для Габи

Общий трекер подготовки ввоза Габи в Таиланд. Cloudflare Worker + Durable Object, вход по общему паролю.

Деплой: Cloudflare → Workers & Pages → Create → Import a repository → `dg-luna-2026`, Root directory `gabi-plan`. Пароль — секрет `PASSWORD` в настройках воркера, в репозитории его нет.
